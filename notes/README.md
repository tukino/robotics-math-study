# Notes / ノート

## English

Write concept notes in your own words. Prefer a compact structure: learning
question, explanation, worked example, retrieval questions, sources, and open
questions. Do not transcribe protected course or textbook content.

## 日本語

概念ノートは自分の言葉で記述します。学習上の問い、説明、計算例、検索練習用の問い、
出典、未解決の疑問という簡潔な構成を推奨します。授業や書籍の保護された内容は転載
しません。
