# 2リンク平面アーム：理論手先位置と実測の最小比較実験

手動で姿勢を変えられる2リンクアームと方眼紙を使い、Python の
`forward_kinematics_2link` が返す手先位置と、真上からの実測を3姿勢で比べる。
画面教材の 150 mm / 120 mm は表示用なので、ここでは実機寸法を自分で測って入れる。

参照：

- 順運動学本体：`src/robotics_math_study/kinematics.py` の `forward_kinematics_2link`
- 同式のブラウザ実装：`docs/js/kinematics.js` の `forwardKinematics2Link`
- 代表姿勢（Case A〜C）：`tests/test_two_link_kinematics.py`、`two_link_frames.py` の `cases`

---

## 1. 座標系と測り方の約束（実験前に固定する）

| 項目 | 決め方 |
| --- | --- |
| 原点 | **肩の回転中心**を方眼紙上の (0, 0) に合わせる。ピンや十字印で固定。 |
| World X | 基準姿勢で上腕が伸びる方向に方眼の横軸を取る（右を +X 推奨）。 |
| World Y | 真上から見て、+X から反時計回りに 90° の方向を +Y。 |
| 角度の正方向 | 真上から見て **反時計回りが正**（教材の `cos` / `sin` と同じ）。 |
| θ₁（肩） | World X から上腕（肩→肘の中心線）までの角。伸び切りで 0°。 |
| θ₂（肘） | **上腕に対する前腕の相対角**。両リンクが一直線（伸び切り）で 0°。前腕の World 絶対角は θ₁+θ₂。 |
| L₁ | 肩回転中心 → 肘回転中心の距離（mm）。リンク外形ではなく **回転中心間**。 |
| L₂ | 肘回転中心 → **手先の目印**までの距離（mm）。 |
| 手先の目印 | 前腕先端に小さな点シール／ピン穴を1つ付ける。L₂ の測点・読み取り点をこれ1点に統一する。 |

実機寸法（空欄に記入）：

- L₁ = ________ mm
- L₂ = ________ mm

（参考：ブラウザ演習の 150 / 120 は L₁:L₂ = 5:4 の画面スケールであり、この欄には使わない。）

---

## 2. 準備と測定手順

1. 方眼紙を机に固定し、肩ピンを (0, 0) に通す。アームは紙面に平行に動かす。
2. 定規で L₁・L₂ を測り、上の空欄に書く（0.5 mm 程度まで）。
3. 分度器または角度目盛り付き関節で θ₁・θ₂ を読む。ゼロは「伸び切り＝0°」に合わせる。
4. 各姿勢でアームを固定したあと、**真上から**手先目印のマス目を読む。または定規で原点から横・縦の距離を測る。
5. 読みは肩原点からの World 座標 (x, y)［mm］とする。マス目の交点に目印が乗らないときは、近い交点からの差分を定規で補う。

撮影する場合は、レンズを紙面の中心付近の真上に置き、枠が方眼の縦横と平行になるようにする（ずれの影響は §5）。

## 3. 3姿勢と記録欄

教材 Case に揃えると、基準→肩だけ→肘だけが一本の線になる。

| 姿勢 | θ₁ | θ₂ | 意図 | 教材との対応 |
| --- | ---: | ---: | --- | --- |
| P0 基準 | 0° | 0° | 両リンクが +X 方向に伸び切り | Case A |
| P1 肩だけ | 30° | 0° | θ₂ は基準のまま、θ₁ のみ変更 | Case B |
| P2 肘だけ | 0° | 45° | θ₁ は基準のまま、θ₂ のみ変更 | （Case C は θ₁=30° なので、基準を P0 にした相対変更） |

実機で 30° / 45° が取りにくいときは、同じ「基準・肩のみ・肘のみ」の構造を保ったまま、読みやすい角度に置き換えてよい。その場合は下表の θ 欄も実測角に書き換える。

### 記録表

| 姿勢 | θ₁ [°] | θ₂ [°] | 理論 x [mm] | 理論 y [mm] | 実測 x [mm] | 実測 y [mm] | Δx | Δy |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| P0 基準 | 0 | 0 |  |  |  |  |  |  |
| P1 肩だけ | 30 | 0 |  |  |  |  |  |  |
| P2 肘だけ | 0 | 45 |  |  |  |  |  |  |

- 理論欄：下の Python 呼び出しで得た `wrist_world`
- Δx = 実測 x − 理論 x、Δy = 実測 y − 理論 y（符号付き）

## 4. 理論値の出し方（既存 Python）

実測した L₁, L₂［mm］と、その姿勢の θ₁, θ₂［度］をそのまま渡す。

```python
from robotics_math_study import forward_kinematics_2link

# 例：P1（肩だけ）。L1/L2 は §1 で測った実機値（mm）を入れる。
pose = forward_kinematics_2link(
    link_length_1=L1,   # 肩〜肘の回転中心間 [mm]
    link_length_2=L2,   # 肘〜手先目印 [mm]
    theta_1_deg=30.0,   # World X からの肩角 [deg]
    theta_2_deg=0.0,    # 上腕に対する肘の相対角 [deg]
)
x_theory, y_theory = pose["wrist_world"]
```

対応ファイル：

| 渡す値 | 引数名 | 定義ファイル |
| --- | --- | --- |
| L₁, L₂, θ₁, θ₂ | `link_length_1`, `link_length_2`, `theta_1_deg`, `theta_2_deg` | `src/robotics_math_study/kinematics.py` |
| 手先の理論座標 | 戻り値 `wrist_world` | 同上 |
| 肘の理論座標（任意検算） | 戻り値 `elbow_world` | 同上 |
| 同式の可視化 | `TwoLinkFrameVisualizer` / Case A–D | `src/robotics_math_study/two_link_frames.py` |
| 数値回帰 | Case A/B/C の期待値 | `tests/test_two_link_kinematics.py` |

P0 / P2 は `theta_1_deg` / `theta_2_deg` だけ表どおりに変える。単位を mm に揃えれば、戻り値の (x, y) も mm で実測と比較できる。

簡易検算（伸び切り P0）：理論手先はおよそ `(L1 + L2, 0)`。

## 5. 結果の読み方（ずれがどう出るか）

- **全体が似た大きさの Δ** → L₁・L₂ の測りすぎ／測り不足、または目印が回転中心から外れている。
- **P1 だけ大きくずれる** → θ₁ のゼロ点や正方向の取り違え（時計回りを正にしていないか）。
- **P2 だけ大きくずれる** → θ₂ を World 絶対角で読んでいないか（相対角であることの取り違え）。伸び切りを 0° にしていないと、肘曲げで系統的にずれる。
- **x と y が入れ替わったように見える** → 方眼の +X/+Y と角度ゼロの向きが教材と不一致。
- **撮影や視線が斜め** → 遠近で手先が原点から遠ざかる方向に伸びて見え、Δ が半径方向に増えやすい。真上読み・定規併用でこの項を抑える。
- **方眼の原点と肩ピンのずれ** → 全姿勢にほぼ同じオフセットが乗り、Δ が姿勢によらず平行移動する。

合格の目安は固定しない。まずは Δ が「リンク長の数 % 以内か」「P1 と P2 で系統が違うか」を見る。
