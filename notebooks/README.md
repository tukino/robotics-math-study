# Notebooks / Notebook

## English

Keep exploratory, executable experiments here. Name them in learning order, for
example `01_unit_circle.ipynb`. Each notebook should state its question,
assumptions, result, and sources. Clear outputs before committing when they are
large or could contain private data.

## 日本語

探索的で実行可能な実験をここに置きます。`01_unit_circle.ipynb` のように学習順で
命名します。各Notebookには、問い、前提、結果、出典を記載します。出力が大きい、
または個人情報を含む可能性がある場合は、コミット前に出力を消去します。
