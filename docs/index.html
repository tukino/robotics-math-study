Robotics Math Study

2リンク平面アームの順運動学と、手先 5 mm 移動に対する一次補正を、同じ画面で体験するブラウザ教材です。 Python 版と同じ式で計算し、初見でもブラウザだけで最後まで試せます。

図・スライダー・順運動学／ヤコビ計算は docs/js/ の共通モジュールです。 次の演習を足すときも同じ ArmView・AngleControls・RoboticsKinematics を再利用できます。

ローカル確認: リポジトリ根から python3 -m http.server 8000 --directory docs → http://127.0.0.1:8000/
